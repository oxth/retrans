# v0.2 Part D — AI providers, multi-language runs, custom instructions — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Translate with OpenAI (ChatGPT), Claude, any OpenAI-compatible API, or a local ACP agent, besides the built-in local model. "Translate missing" runs several languages at once, and custom instructions steer the results.

**Architecture:**
- **Network and process work happens in Rust.**
  - Rust reads API keys from the OS credential store itself. The web page can set or delete a key but never read one.
  - Rust makes the HTTP calls (reqwest is already a dependency), with retry and cancel.
  - Rust runs the ACP client over stdio.
- **The TypeScript side has one `Translator` interface** with three implementations:
  - local, which wraps today's `translateText`;
  - cloud, which batches strings and target languages into one JSON-reply request;
  - acp, the same batching through an agent.
- **One generalized multi-language `translateMissing` drives them all.**
- **Placeholder protection and machine/needs-review marking stay exactly as today.**

**Tech Stack:** Rust (Tauri 2, reqwest, tokio, and one new crate `keyring`), TypeScript/React/Zustand/Vitest.

**Spec:** `docs/superpowers/specs/2026-11-04-retrans-v0.2-additions-design.md`, Part D (D1–D5) and Part A's credential-store rule. Quality bar:
- each provider tested against a local fake server (OpenAI-style, Anthropic-style, ACP fake agent over stdio);
- placeholder safety and batching;
- permission requests refused;
- no network call when only the local model is enabled.

**Builds on (`main` after the Preferences branch merges):**
- `PreferencesPage` holds the machine-translation section (`MtSettings` with `session={null}`);
- per-tab runs (`src/ui/runs.ts`, undo group per run);
- `translateMissing(..., write)` in `src/mt/batch.ts`.

## Global Constraints

- **Providers:** `local` (the default), `openai`, `anthropic`, `compatible`, `acp`. Labels:
  - `Built-in (on this computer)`;
  - `OpenAI (ChatGPT)`;
  - `Claude (Anthropic)`;
  - `OpenAI-compatible`;
  - `AI agent (ACP)`.
- **Credential-store names:** service `com.retrans.app`, accounts `openai`, `anthropic` and `compatible:<baseUrl>`. The key never goes into prefs, project files, logs or JS memory beyond the input field.
- **Keychain denied or cancelled message:** `Couldn't read the API key — re-enter it in Settings.`
- **Opt-in:** the first time a non-local provider is turned on, a confirmation appears: `Text you translate will be sent to <provider name> (<host or command>). Continue?` Accepted providers are remembered in prefs `mt.consent: string[]`.
- **While translating:** the run shows `Translating with <provider label>…`.
- **What's sent per string:**
  - masked text;
  - key name;
  - group;
  - base-language text;
  - existing translations in other languages;
  - the combined instructions.
- **Batching:** at most **20 strings** per request, with all of each string's target languages in the same request.
- **Retries:** HTTP 429 and 5xx are retried 3 times with 1 s / 2 s / 4 s backoff, honouring `Retry-After`. Error copy:
  - 401/403: `The API key was rejected.`;
  - 429 after the retries: `Rate limited — try again in a minute.`;
  - anything else: `<Provider>: <message from the response>`.
- **ACP:**
  - `initialize` with `clientCapabilities: { fs: { readTextFile: false, writeTextFile: false }, terminal: false }`;
  - `session/new` with `cwd` = a fresh empty temp directory (never the project) and `mcpServers: []`;
  - `session/prompt` with one text block;
  - collect the `session/update` `agent_message_chunk` text;
  - **every `session/request_permission` is answered `{ outcome: { outcome: "cancelled" } }`**;
  - any `fs/*` or `terminal/*` request gets JSON-RPC error `-32601`.
  - Presets: `Claude Code`, `Codex`, `Gemini CLI`, plus `Custom command`. Verify the current commands against each project's docs at implementation time and ledger them.
- **Custom instructions:**
  - The three levels are combined in the order all projects → this project → this language, separated by a blank line.
  - "This project" and "this language" are stored in `.retrans/state.json` as `project.instructions: { all?: string; byLocale?: Record<string,string> }`.
  - "All projects" is stored in prefs `mt.instructions`.
  - Instructions are used by cloud, ACP and Qwen-template local models, and ignored by TranslateGemma. The Settings note says: `TranslateGemma uses a fixed prompt and ignores custom instructions.`
- **No network when only `local` is enabled.** A test asserts that no cloud or ACP command is invoked.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Before each commit: `pnpm test`, `pnpm exec tsc --noEmit`, and `cargo test` + `cargo clippy --all-targets -- -D warnings` when Rust changed.

## Review Focus

1. **A model reply that isn't the JSON asked for** (prose around it, code fences, a missing id, an extra language, truncated output). Valid entries are used; missing ones count as failed with `The model's reply was incomplete.`; nothing throws. Pinned by `parseBatchReply tolerates fences and prose, reports missing ids` (Task 4).
2. **A cloud reply that drops or alters a placeholder** in one of 20 strings. Only that string is "couldn't be translated safely"; the other 19 are written. Pinned by `one unsafe string in a batch doesn't sink the batch` (Task 5).
3. **Cancel during a slow cloud request or an agent turn.** The request is aborted (HTTP) or `session/cancel` is sent (ACP), and nothing arriving later is written. Pinned by `cancel aborts the HTTP request` (Task 2) and `cancel sends session/cancel and drops late chunks` (Task 3).
4. **An ACP agent that asks for permission or tries to read a file.** It is refused every time and the turn still finishes. Pinned by `permission requests are refused and fs requests error` (Task 3).
5. **A key is removed from the credential store, or access is denied, after an update.** The run stops with the Keychain message, not a crash, and the provider stays configured. Pinned by `missing key gives the re-enter message` (Task 1/2).

**Interfaces:**

- Endpoints:
  - OpenAI and compatible: `POST {base}/chat/completions` (base defaults to `https://api.openai.com/v1`), `Authorization: Bearer <key>`, `messages: [system, user]`, `temperature: 0`. The reply is `choices[0].message.content`.

- `mt_cloud_models(provider, base_url) -> Result<Vec<String>, String>`: `GET {base}/models`; Anthropic `GET /v1/models`. Returns ids sorted.
- `mt_cloud_cancel(req_id)`: aborts that in-flight request (keep a `Mutex<HashMap<u64, AbortHandle>>` in managed state).
- The key comes from `secret_get(account)`. A compatible endpoint with no stored key sends no auth header (Ollama, LM Studio).
- Retries and error copy are as in Global Constraints. The base URL is made overridable for tests.

### Task 4: Batch prompt and reply (TS, pure)

**Files:**
- Create: `src/mt/cloud-prompt.ts`, `src/mt/cloud-prompt.test.ts`
- Modify: `src/mt/prompt.ts` (the Qwen template appends instructions to its system line; TranslateGemma unchanged)

**Interfaces:**

```ts
export interface BatchString { id: KeyId; key: string; group: string; masked: string; base: string; others: Record<string, string> }
export function buildBatchPrompt(a: { src: string; targets: string[]; strings: BatchString[]; instructions: string }): { system: string; user: string };
export function parseBatchReply(text: string, ids: KeyId[], targets: string[]): { values: Map<KeyId, Map<string, string>>; missing: Array<{ id: KeyId; locale: string }> };
export function combineInstructions(global: string | undefined, project: string | undefined, locale: string | undefined): string;
```

- **The system text** says what the app is, gives the rules (keep every `[[n]]` token exactly, keep line breaks, output only JSON), and adds the instructions.
- **The user text** is JSON:
  - `{ "source": "<src>", "targets": [...], "strings": [{ "id", "key", "group", "text": masked, "base", "others" }] }`;
  - the reply must be `{ "<id>": { "<locale>": "<text>" } }`.
- **`parseBatchReply`:**
  - strips code fences and any text before the first `{` or after the last `}`;
  - ignores unknown ids and locales;
  - lists every expected id × target that is absent as `missing`.

### Task 5: Translators and multi-language Translate missing (TS)

**Files:**
- Create: `src/mt/translator.ts`, `src/mt/translator.test.ts`
- Modify: `src/mt/batch.ts` (`translateMissingMulti`), `src/ui/runs.ts` (multi-locale phase), `src/platform/mt.ts` (invoke wrappers for the Task 2/3 commands)

**Interfaces:**

```ts
export interface TranslateJob { id: KeyId; locale: string; source: string }    // one cell
export interface Translator {
  readonly label: string;      // provider label, for "Translating with …"
  readonly remote: boolean;    // false only for local
  translate(jobs: TranslateJob[], ctx: { session: ProjectSession; instructions: (locale: string) => string },
            onResult: (job: TranslateJob, r: TranslateResult) => void, signal: AbortSignal): Promise<void>;
}
export function localTranslator(engine: MtEngine, model: ActiveModel, format: Format): Translator;  // one job at a time, today's translateText
export function cloudTranslator(cfg: CloudConfig, format: Format): Translator;  // batches ≤20 strings with all their locales per request
export function acpTranslator(cfg: AcpConfig, format: Format): Translator;
export async function translateMissingMulti(session, locales: string[], ns: string, translator: Translator,
  onProgress: (p: { perLocale: Record<string, { done: number; total: number }>; current: KeyId | null }) => void,
  signal: AbortSignal, write?: (fn: () => void) => void): Promise<Record<string, BatchResult>>;
```

- Remote translators `protect()` each string, send masked text, `restore()` each result, and map a restore failure to `unsafe` for that cell only.
- Writes stay `setText(..., { machine: true })` and skip cells filled meanwhile, as today.
- `runs.ts` `RunPhase` "running" gains `perLocale`; "done" holds `results: Record<locale, BatchResult>`.
