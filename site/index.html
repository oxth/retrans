Features

Everything your translations need

One grid for every key and language. Missing translations are impossible to miss, and saving changes only what you edited.

JSON and TypeScript

Open next-i18next and Paraglide projects directly, or import TypeScript locale modules into a workspace that syncs when your code changes and writes back a minimal diff.

Figma Variables New in 0.2

Open Figma .tokens.json exports, translate them, link them to your code keys, and export back. Only the text changes.

Local or cloud AI New in 0.2

A built-in model runs entirely on your computer. Or use OpenAI, Claude, any OpenAI-compatible API, or an AI agent you already have (Claude Code, Codex, Gemini CLI).

Many languages at once New in 0.2

Translate every missing string in all your languages in one run, with your own instructions for tone and terms.

Review status that travels

Every translation shows whether it's missing, waiting for review or reviewed, and flags it when the source text changes. Status lives in .retrans/ and is shared through git.

Tabs, auto-save, undo

Keep several projects open, never lose an edit, and undo anything, including a whole AI translation run.

Translator packages

Send a .zip to a translator. They open it in Retrans and send it back, and you import their work with a clear view of what changed.

Your text stays yours

No account, no telemetry. Text leaves your computer only if you choose a cloud provider, and Retrans asks first. API keys live in your system keychain.

Install

Up and running in a minute

Download, open, and point Retrans at your project folder.

macOS

  1. Open the downloaded .dmg and drag Retrans into Applications.
  2. The first time you open it, macOS may say it can't check the app. Open System Settings → Privacy & Security and choose Open Anyway, or right-click Retrans in Applications and choose Open.

Windows

  1. Run the downloaded Retrans_…_x64-setup.exe.
  2. If SmartScreen says it protected your PC, click More info → Run anyway.

Linux

  1. Make the downloaded AppImage executable with chmod +x Retrans_*.AppImage, then run it. If it doesn't start, install libfuse2 (libfuse2t64 on Ubuntu 24.04).
  2. On Debian or Ubuntu you can use the .deb package instead: sudo apt install ./Retrans_*_amd64.deb. It doesn't update itself; install the newer .deb to update.

Retrans updates itself on macOS, Windows and with the Linux AppImage: once installed, new versions are offered inside the app.
