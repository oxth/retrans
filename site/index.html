Retrans is a free desktop app for editing next-i18next, Paraglide, TypeScript and Figma translations in one grid, with local or cloud AI to fill the gaps.

Download for macOSApple Silicon (M1 and later) Download for WindowsWindows 10 and 11 (64-bit)

Latest release · Free, no account · All releases

Everything your translations need

One grid for every key and language. Missing translations are impossible to miss, and saves change only what you edited.

Formats

next-i18next, Paraglide, TypeScript

Open JSON projects directly, or import TypeScript locale modules into a workspace that syncs when your code changes and writes back a minimal diff.

New in 0.2

Figma Variables

Open Figma .tokens.json exports, translate them, link them to your code keys, and export back. Only the text changes.

AI

Local or cloud translation

A built-in model runs entirely on your computer. Or use OpenAI, Claude, any OpenAI-compatible API, or your own AI agent (Claude Code, Codex, Gemini CLI).

New in 0.2

Many languages at once

Translate every missing string in all your languages in one run, with your own instructions for tone and terms.

Workflow

Tabs, auto-save, undo

Keep several projects open, never lose an edit, and undo anything, including a whole AI translation run.

Review

Review status that travels

Each cell tracks whether it's translated, machine-translated or reviewed. Status is stored in .retrans/ and shared through git.

Teams

Translator packages

Send a .zip to a translator. They open it in Retrans and send it back, and you import their work with a clear view of what changed.

Privacy

Your text stays yours

No account, no telemetry. Text leaves your computer only if you choose a cloud provider, and Retrans asks first. API keys live in your system keychain.

Install

Retrans updates itself: once installed, new versions are offered inside the app.

macOS

  1. Open the downloaded .dmg and drag Retrans into Applications.
  2. The first time you open it, macOS may say it can't check the app. Open System Settings → Privacy & Security and choose Open Anyway, or right-click Retrans in Applications and choose Open.

Windows

  1. Run the downloaded Retrans_…_x64-setup.exe.
  2. If SmartScreen says it protected your PC, click More info → Run anyway.
